# 实例访问与网络

## 网页控制台

实例详情的「控制台」提供串口与 KVM 图形显示器。串口通过 Incus `POST /1.0/instances/<name>/console` 的 `console` 类型连接，VNC 使用 `vga` 类型，由 noVNC 显示。浏览器只连接面板同源 WebSocket，面板校验登录、实例归属、封禁 / 挂牌状态与 Origin，再通过固定服务端指纹的 Incus 连接转发数据。只读 API 令牌不能连接控制台。

控制台无需虚拟机内的 incus-agent。VNC 支持查看固件、引导和恢复环境，串口需要镜像内配置登录服务，例如使用 systemd 的镜像启用 `serial-getty@ttyS0.service`，并按发行版配置内核 `console=ttyS0` 参数。串口登录与图形系统登录使用系统账号密码；关闭网页只分离控制台，不关闭虚拟机。30 分钟没有输入会断开连接，可在页面重新连接。

反向代理需允许 `/api/instances/*/console` 与 `/api/admin/instances/*/console` 的 WebSocket Upgrade，保持原 Host / Origin；无需开放宿主机 VNC 端口。Incus 版本需支持 `console` 和 `console_vga_type` API 扩展。mock 节点只模拟文本控制台，不模拟 VNC 图形显示。

## IPv6 分配

在支持 IPv6 的宿主机设置：

1. 地址池，例如 `2001:db8::/48`（文档示例地址，生产环境换为上游实际分配并路由到此宿主机的网段）。
2. routed 父接口，例如 `eth0`，并按 Incus routed NIC 要求启用 IPv6 转发及代理 NDP。
3. 每份前缀长度，例如 `64`。默认 `128` 为单地址，与原有配置兼容。

套餐的 IPv6 数量表示分配份数，每份独占一个网段。分配器跳过首个子网，避开数据库内已有地址与网段，在节点分配锁和事务内预留；删除实例会释放分配。节点前缀设置仅影响新分配，现有实例与迁移回滚保留已有分配。迁往不同地址池时重新分配主地址和网段。

Incus `eth1` routed NIC 的 `ipv6.address` 配置主地址，`ipv6.routes` 配置整个独占网段；容器由 Incus 配置主地址，KVM 由 cloud-init 按 MAC 匹配网卡配置主地址 `/128` 与 `fe80::1` 默认路由。用户可在实例内增加分配网段中的地址，或自行配置进一步路由。修改系统网络前保留控制台入口。

上游必须支持整段路由到宿主机；面板分配不会使未授权或上游未路由的网段变得可达。普通公网接口 `/64` 的 SLAAC / NDP 接入不能直接等同于上游路由前缀委派。

## 无 incus-agent 的流量与命令

宿主机 Agent 0.8.0 起提供 `host-traffic` 和 `guest-exec` 能力，仍为独立的 Go 二进制，不要求在虚拟机中安装面板 Agent。

流量通过本机 Incus 读取 eth0 / eth1 的 `volatile.<device>.host_name`，再读取 Linux `/sys/class/net/<host-interface>/statistics/`。宿主机 TX 对应实例入站，RX 对应实例出站。VPC 与系统其他网卡不计费。每次心跳采样并上报全部受管实例，面板在数据库事务内同时更新基线、周期用量与每日汇总；首次切换来源只建基线，不重复计入旧来源的累计值。周期重置保留计数基线。boot-id、实例 UUID、ifindex 共同识别网卡代次。

开始使用宿主机计数后，Agent 暂时离线不会回退到另一来源的累计值。恢复后仍存在的网卡可按原基线补算；已销毁网卡最后一段未采集流量无法恢复。旧版 Agent 保持原 Incus 统计方式，需要升级才能获得独立采集能力。

命令正常优先使用 Incus exec。仅当错误表明虚拟机 incus-agent 不可用，才创建有期限的 SSH 任务：

1. 面板检查实例及宿主机在线能力，选用实例内网 IPv4、独立 IPv4 或已分配的公网 IPv6。
2. 使用 HMAC 签名回复向当前宿主机下发任务。Redis 中的命令、密码及结果使用应用密钥加密，不把密码放进系统进程参数。
3. 宿主机再次通过本机 Incus 核对实例类型、运行状态和面板 ID，以保存的 root 密码连接 SSH 22 端口。SSH 主机密钥按项目、实例 UUID 与面板记录的重装时间保存在 `/var/lib/paledove/guest-known-hosts/`，首次信任，之后拒绝变化。
4. 任务受截止时间和命令超时限制，回传失败时在当前 Agent 进程内重传缓存结果，避免重复执行。面板仅在命令成功后更新保存的密码。

如需手动补齐宿主机依赖：Debian / Ubuntu 安装 `openssh-client`，RHEL 系安装 `openssh-clients`。Agent 自升级只替换二进制，不安装系统软件；旧宿主机可重新运行 Agent 安装脚本或手动安装该依赖。

如果系统禁用 root 密码登录、密码被用户在系统内修改、SSH 主机密钥异常或网络不可达，备用通道会失败。请通过控制台确认原因；在面板中重装系统后会使用新的密钥记录，不自动删除旧实例的信任记录。磁盘加密、无可用登录凭据等情况需要系统自身的恢复流程，面板不会静默关机修改磁盘或绕过认证。
